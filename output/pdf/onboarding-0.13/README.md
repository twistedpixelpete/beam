# Beam 0.13.0 — Internal Production Beta

Twisted Pixel · Tested with Blender 5.2.2 LTS / macOS 26.7.

Start with **Beam_Quick_Start.pdf**, then open a copy of **Beam_Training_Project.blend** and follow **Beam_Training_Project_Guide.pdf**. **Beam_User_Guide.pdf** covers the complete workflow and a Where Is It reference. The editable manual is **Beam_User_Guide.docx**; source content is `manual-content.json`, with the builder in `tools/onboarding` at the repository root.

Install the supplied `install/beam-0.13.0.zip`. Keep it zipped; use Blender Preferences → Add-ons → Install from Disk. Restart after replacing an earlier build. Use the supplied archive because it includes the workspace menu integration correction.

This package adds all five Surface Analysis modes, lux assumptions/ranges, Projection Distance and Observer/Acuity guidance. It retains the three-projector blend, curved receiver, UV chart, movable blocker and optics examples. Nine saved cameras and 21 exercises are included. The original 0.12 documentation baseline remains archived unchanged.

See `validation/VALIDATION_REPORT.md` for the exact acceptance scope. Exported CSVs, analysis sidecars and `Training_Study_Package` are worked examples, not additional installation files. Beam remains in testing; this is not a public stable release.
