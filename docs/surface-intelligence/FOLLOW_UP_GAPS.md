# Follow-up gaps for review

Observed useful reference capabilities, deliberately not added to this milestone:

- Logarithmic photometric scale for studies spanning a large intensity range.
- Explicit blend-attenuated brightness preview, distinct from raw additive incident light. Requires a defined edge-blend attenuation model.
- Per-surface analysis summary across multiple receivers; Beam currently analyses one chosen receiver.
- Observer look-through composition controls. Beam's Observer is deliberately an eye-position Empty, not a camera.
- Luminance is a future possibility only with a clearly separated reflectance/observer model; it is out of scope here.

No verified numeric MM distance or human-acuity metric was located. Their absence from the inspected UI is recorded as a comparison limitation, not a request to add speculative features. Do not copy an undefined focus metric.
